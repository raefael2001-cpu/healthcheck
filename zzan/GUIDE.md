# 짠(ZZAN) 앱 만들기 — 문과생을 위한 처음부터 출시까지

> **목표:** 기획서(`spec.md`)의 핵심만 살려서, 코딩을 몰라도 혼자 **5~6주 안에 구글 플레이에 출시**하기.
> **방법:** 코드는 직접 쓰지 않고 **Claude Code에게 한 기능씩 시킨 뒤 폰으로 확인**합니다. 바디체크 앱을 만들 때와 같은 방식입니다.

---

## 0. 큰 그림 — 식당에 비유하면

- **홀 (화면, 프론트엔드):** 손님이 보는 곳. 카드, 버튼, 큰 글씨.
- **주방 (서버, 백엔드):** 손님 눈에 안 보이는 곳. 주문을 받아 요리(건배사 생성)를 함.
- **셰프 (AI, LLM):** 주방에서 새 요리를 즉석으로 만드는 사람. 여기서는 Claude.
- **반찬통 (프리셋):** 미리 만들어 둔 건배사 200개. 셰프가 실수하거나(오류) 정전이 나도(지하 술집, 인터넷 끊김) 바로 꺼내 줌.
- **법인카드 (API 키):** 셰프를 부를 때 쓰는 결제 수단. **반드시 주방 금고에 보관.** 홀(앱 화면 코드)에 두면 아무나 가져다 씀.
- **백화점 입점 (스토어 출시):** 완성한 가게를 구글 플레이라는 백화점에 입점시키는 것. 입점 심사가 있음.

기획서는 큰 레스토랑 설계도입니다(Flutter, FastAPI, Redis, Supabase…). 처음에는 **포장마차**로 시작해서 손님 반응을 보고 키웁니다.

## 1. 기획서를 심플 버전으로 바꾸기

| 기획서 | 심플 버전 | 이유 |
|---|---|---|
| Flutter 앱 | 웹앱(PWA) | 바디체크와 같은 방식. 폰 브라우저로 바로 확인하고, 나중에 앱으로 포장 |
| FastAPI 서버 + Redis | 1차 출시엔 없음, 2차에 '서버 함수' 1개 | 관리할 서버가 없음 |
| Supabase DB | 없음. 즐겨찾기는 폰 안에 저장 | 회원가입·개인정보 걱정 없음 |
| Hive 오프라인 프리셋 | 앱 안에 건배사 파일 포함 | 지하 술집에서도 작동 |
| 실시간 밈 파이프라인 | 밈 건배사에 '등록일'만 기록 | 3개월 지나면 자동으로 숨김 |
| 피드백 API | 카드에 👍/👎 (폰에 저장) | 서버 없이 가능 |
| Claude 3.5 Haiku | Claude Haiku 5.5 | 지금 기준 빠르고 저렴한 최신 모델 |
| 스와이프·흔들기·화면 켜짐·큰 글씨 | **그대로** | 웹 기술로 모두 가능 |

- **1차 출시(MVP):** AI 없이 **잘 다듬은 건배사 200개**로 승부.
- **2차 업데이트:** AI 즉석 생성 추가.

> **왜 AI를 나중에?** 건배사 앱의 품질은 결국 '문장'입니다. AI가 쓴 문장도 사람이 검수해야 하고, 좋은 예시 200개가 있어야 AI에게 "이런 느낌으로"라고 가르칠 수 있습니다. 문과생의 강점이 가장 크게 발휘되는 부분입니다.

## 3. 단계별 진행

### 1단계. 건배사 콘텐츠 만들기 (1주차, 코딩 없음) ⭐ 가장 중요

구글 스프레드시트에 아래 칸으로 정리합니다. **한 줄 = 카드 1장.**

| 제시어 | 대상 | 1행 | 2행 | 구호 | 기술 | 밈 | 밈 등록일 |
|---|---|---|---|---|---|---|---|
| 연봉 | 동기 | 연차 쓰고 놀러 갈 생각만 하지 말고, | 봉!·인!·해!·제!·원!·샷! | 봉인해제! | 스타카토 | | |
| 건강 | 부장님 | 건배 잔 높이 들고, 올 한 해 고생 많으셨습니다! | 강철 체력 우리 팀, 다 같이 짠! | 짠! | 크레센도 | | |
| 축하 | 청첩장 | 축복받은 두 사람의 앞날에, | 하늘만큼 땅만큼 행복하라, 짠! | 행복하라! | 콜&리스폰스 | | |

- **대상:** 부장님 / 동기 / 청첩장 / 가족 (기획서 2.1 표 참고)
- **기술:** 스타카토 / 크레센도 / 훅&드롭 / 콜&리스폰스
- **목표:** 자주 나오는 제시어 50개 × 대상 4개 = **200개** (처음엔 50개로 시작해도 됨)

**만드는 법**

1. Claude에게 초안을 요청합니다 (아래 문장 복사).
2. **직접 소리 내어 읽고** 고칩니다. ← 이게 핵심 작업
3. 검수 체크리스트
   - [ ] 1행 첫 글자 = 제시어 첫 글자, 2행 첫 글자 = 제시어 둘째 글자
   - [ ] 마지막 단어가 '짠!', '샷!'처럼 받침이나 된소리로 끝나는가 (타격감)
   - [ ] 부장님 모드에 퇴사·야근·자학 개그가 없는가 / 청첩장 모드에 전 연인 뉘앙스가 없는가
   - [ ] 5초 안에 외울 수 있는 길이인가
   - [ ] 밈을 썼다면 지금도 통하는 밈인가 (기획서 예시의 '럭키비키', '폼 미쳤다' 등은 2023~24년 유행이라 지금은 '만료' 쪽입니다)

> 📋 **Claude에게 복사해서 보내기**
>
> 회식 건배사 2행시 초안 20개 만들어줘. 제시어는 [건배, 사랑, 행복, 건강, 성공], 대상은 부장님/동기/청첩장/가족 각 1개씩. 1행은 제시어 첫 글자, 2행은 둘째 글자로 시작해. 마지막은 받침 있는 짧은 구호로 끝내. 표로 정리해줘: 제시어, 대상, 1행, 2행, 구호, 기술(스타카토/크레센도/훅&드롭/콜&리스폰스 중 1개).

다 만들면 스프레드시트를 **CSV로 다운로드**합니다 (파일 → 다운로드 → CSV).

### 2단계. 화면을 종이에 그려 보기 (1주차, 30분)

화면은 4개면 충분합니다.

1. **홈:** 대상 버튼 4개(부장님/동기/청첩장/가족) + 밈 켜기/끄기 + 제시어 입력칸(선택) + "흔들면 랜덤!" 안내
2. **카드 덱:** 건배사 카드. 오른쪽으로 밀면 저장, 왼쪽으로 밀면 다음 카드. 카드에 발성 기술 표시(스타카토면 ● ● ●)
3. **큰 글씨 모드:** 카드를 탭하면 검은 바탕에 아주 큰 흰 글씨. 5분간 화면 꺼짐 방지
4. **즐겨찾기:** 오른쪽으로 밀어 저장한 카드 목록

그린 종이를 폰으로 찍어 두었다가 3단계에서 Claude Code에게 보여 주면 좋습니다.

### 3단계. Claude Code로 앱 만들기 (2주차)

**규칙 3가지**

- 한 번에 **한 기능만** 시킨다.
- 시킨 뒤에는 **반드시 폰으로 확인**한다.
- 이상하면 "이렇게 했더니 → 이렇게 됐는데 → 원래는 이래야 해"로 말한다. 스크린샷이 가장 좋다.

**준비:** GitHub에서 새 저장소 `zzan`을 만들고 → 그 저장소로 Claude Code 세션을 시작 → 기획서(`spec.md`)와 건배사 CSV를 첨부합니다.

**아래 순서대로 하나씩 복사해서 요청하세요.**

> **① 뼈대**
> 기획서(spec.md)를 읽고 짠 앱의 1차 버전을 웹앱(PWA)으로 만들 거야. 서버·로그인·AI 없이 시작해. 먼저 첨부한 건배사 CSV를 앱에서 쓸 수 있는 데이터 파일로 바꾸고, 홈 화면(대상 4개 버튼 + 밈 켜기/끄기)과 카드 1장 보여주기까지만 만들어줘. 문과생도 알 수 있게 파일마다 역할을 설명해줘.

> **② 스와이프**
> 카드를 오른쪽으로 밀면 즐겨찾기에 저장(폰에 저장)되고 큰 글씨 화면으로 가고, 왼쪽으로 밀면 다음 카드가 나오게 해줘. 부드럽게 움직이게.

> **③ 큰 글씨 + 화면 켜짐 유지**
> 카드를 탭하면 검은 바탕 흰 글씨로 아주 크게(폰을 테이블에 두고 1m 떨어져서 읽힐 정도) 보여줘. 이 화면에서는 5분간 화면이 꺼지지 않게 해줘.

> **④ 발성 기술 표시**
> 카드에 발성 기술을 보여줘. 스타카토는 음절마다 ● 표시, 크레센도는 글씨가 점점 커지게, 콜&리스폰스는 '선창/후창'으로 나눠서.

> **⑤ 흔들기 랜덤**
> 폰을 흔들면 지금 고른 대상에 맞는 랜덤 카드가 바로 뜨게 해줘. 아이폰에서 권한 요청 버튼이 필요하면 넣어줘.

> **⑥ 오프라인 + 설치**
> 인터넷이 끊겨도 모든 기능이 되게 하고, 홈 화면에 앱처럼 설치되게 해줘. 앱 이름은 '짠', 아이콘도 만들어줘.

> **⑦ 밈 수명**
> 밈 건배사는 '밈 등록일'로부터 3개월이 지나면 자동으로 안 보이게 해줘. 밈 끄기를 하면 밈 카드는 빼줘.

각 단계가 끝날 때마다 **"커밋하고 푸시해줘"** 라고 말하세요. (= 저장 + GitHub에 백업)

### 4단계. 인터넷에 올리기 (2주차, 10분)

1. vercel.com 접속 → **GitHub로 로그인**
2. Add New → Project → `zzan` 저장소 선택 → Deploy
3. `zzan.vercel.app` 같은 주소가 생김 → 폰 크롬에서 열고 '홈 화면에 추가'
4. 이제부터 Claude Code가 푸시할 때마다 **사이트가 자동으로 업데이트**됨

> **왜 바디체크 때 쓴 GitHub Pages가 아니라 Vercel?**
> ① 나중에 AI 기능용 '주방(서버 함수)'까지 한곳에 둘 수 있고, ② 구글 플레이 포장 때 필요한 인증 파일을 올리기 쉽습니다.
> ⚠️ Vercel 무료 요금제는 비상업용입니다. 광고나 유료 기능을 붙이면 요금제를 바꾸거나 다른 곳으로 옮겨야 합니다.

### 5단계. 실전 테스트 (3주차)

지인 5~10명에게 주소를 보내고 실제 술자리에서 써 보게 합니다.

- [ ] 비행기 모드(지하 술집 상황)에서도 카드가 나오는가
- [ ] 앱을 열고 3초 안에 쓸 만한 카드가 나오는가
- [ ] 폰을 테이블에 두고 1m 거리에서 읽히는가
- [ ] 가방 속에서 흔들려 엉뚱하게 작동하지 않는가
- [ ] 어떤 건배사가 실제로 터졌는가 → 그 스타일을 더 만든다

### 6단계. (선택) AI 즉석 생성 붙이기

프리셋에 없는 단어를 지목받았을 때 AI가 즉석에서 만들어 주는 기능입니다. **1차 출시 후에 해도 됩니다.**

1. console.anthropic.com 가입 → 결제 수단 등록 → **월 사용 한도를 꼭 설정** → API 키 발급
2. Vercel 프로젝트 → Settings → Environment Variables에 `ANTHROPIC_API_KEY`라는 이름으로 키를 저장
   (**키를 코드나 채팅창에 붙여 넣지 마세요.** 법인카드를 홀에 두는 것과 같습니다.)
3. Claude Code에게 요청:

> 📋 Vercel 서버 함수로 /api/generate를 만들어줘. 제시어(한글 2글자)와 대상을 받아서 Claude Haiku 5.5로 2행시 건배사를 만들고, 기획서 5장의 규칙과 우리 프리셋 중 좋은 예시 5개를 참고하게 해. API 키는 환경변수 ANTHROPIC_API_KEY에서 읽어. 결과의 각 행 첫 글자가 제시어와 맞는지 검사하고, 틀리거나 5초 넘게 걸리거나 오류가 나면 프리셋 카드를 대신 보여줘. 같은 폰에서 하루 30번 넘게 못 부르게 해줘. AI가 만든 카드에는 '부적절한 내용 신고' 버튼을 달아줘.

> **신고 버튼은 왜?** 구글 플레이는 AI로 콘텐츠를 만드는 앱에, 사용자가 부적절한 결과를 신고할 수 있는 기능을 요구합니다.

### 7단계. 구글 플레이 출시 (3~6주차)

웹앱을 **PWABuilder**라는 무료 도구로 '앱 상자'에 포장해서 올립니다.

**① 개발자 계정 (1주차에 미리)**

- play.google.com/console → **개인** 계정 → 25달러 결제 → 신분증 인증

**② 포장하기**

1. pwabuilder.com에 내 사이트 주소(`zzan.vercel.app`) 입력 → 점검 결과 확인
   (빨간 항목은 Claude Code에게 "PWABuilder에서 이 항목이 빨간색이야, 고쳐줘")
2. Package for stores → **Android** 선택
3. 패키지 이름 입력. 예: `com.내영문이름.zzan` (**출시 후에는 못 바꿈**)
4. 다운로드한 zip 안의 파일 3종:
   - `.aab` 파일 → 구글 플레이에 올릴 앱 파일
   - **서명 키 파일과 비밀번호** → '이 앱 주인은 나'라는 도장. 업데이트할 때마다 필요. 구글 드라이브 등 **두 곳에 백업**하고, GitHub 저장소에는 **절대 올리지 않기**
   - `assetlinks.json` → Claude Code에게 "이 파일을 사이트의 /.well-known/assetlinks.json 경로에 올려줘" (안 하면 앱 위에 주소창이 보임)

**③ 스토어 등록 정보 준비**

- 앱 이름 (예: "짠 - 3초 건배사"), 짧은 설명(80자 이내), 자세한 설명
- 아이콘 512×512, 그래픽 이미지 1024×500, 폰 스크린샷 2장 이상 → Claude Code에게 만들어 달라고 해도 됨
- **개인정보처리방침 주소** → "개인정보를 수집하지 않습니다" 페이지 하나. Claude Code에게 privacy.html을 요청
- **콘텐츠 등급 설문** → 술 관련 내용이 있으니 **솔직하게 '예'**. 대상 연령은 성인으로 설정

## 6. 용어 사전

- **PWA:** 홈 화면에 설치되고 오프라인에서도 되는 웹사이트
- **커밋 / 푸시:** 저장 / GitHub에 백업 업로드
- **배포:** 사람들이 접속할 수 있는 주소에 올리기
- **API:** 앱이 서버에 보내는 주문서 양식
- **API 키:** 유료 서비스용 비밀 열쇠 (법인카드)
- **환경변수:** 서버 안에 숨겨 두는 설정값 (키 보관 금고)
- **.aab:** 구글 플레이에 올리는 앱 파일
- **서명 키:** '이 앱 주인은 나'를 증명하는 도장. 잃어버리면 업데이트가 어려워짐
- **TWA:** 웹앱을 안드로이드 앱으로 감싸는 방식 (PWABuilder가 해 줌)
