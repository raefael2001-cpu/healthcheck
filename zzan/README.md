# 짠 (ZZAN)

회식 건배사를 카드로 넘겨 보고, 고른 건배사는 크게 띄워 읽는 웹앱입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `app/index.html` | 앱 (공개용). 파일 하나로 동작 |
| `cards-notes.csv` | 직접 모은 건배사 노트. 앱에서 가장 먼저 보여 줌 |
| `presets-draft.csv` | AI가 쓴 2행시·3행시 초안. 앱에서 'AI 초안'을 켜야 보임 |
| `build.py` | CSV를 앱 안의 데이터로 넣는 스크립트 |
| `GUIDE.md` | 처음부터 출시까지 단계별 안내 |
| `keywords.md` | 초안에 쓴 제시어 목록 |
| `spec.md` | 처음 기획서 |

## 카드를 고칠 때

1. CSV를 고칩니다. 한 줄이 카드 1장입니다.
2. `python3 zzan/build.py`를 실행합니다.

### `cards-notes.csv`의 칸

- **형식:** 대본 / 이야기 / 줄임말 / 행시 / 구호
- **제목, 테마:** 카드 위쪽에 보이는 이름과 한 줄 설명
- **대상:** 부장님 / 동기 / 친목 / 가족 / 맞춤. 여러 개면 `/`로 나눔
- **자리:** 송년회, 신년회, 송별회 등. 비우면 언제나 쓰는 카드
- **이야기:** 구호 앞에 하는 말. `{잔을 들며}`처럼 중괄호 안은 지문
- **1행~4행:** 삼행시·줄임말의 각 줄. `[소]통과`처럼 대괄호 안의 글자가 강조됨
- **선창, 후창:** 앱이 "제가 ‘선창’ 하면 ‘후창’ 외쳐 주십시오"를 자동으로 붙임
- **덧붙임:** 카드 아래 작은 글
- **달:** 그 달에만 보여 줌 (예: `11`)
- **만료일:** 이 날이 지나면 숨김 (예: `2026-12-31`)
- **추천:** `1`을 넣으면 먼저 보여 줌

## 보여 주는 순서

내 노트 → 고른 자리에 맞춘 카드 → 추천 → 나머지. AI 초안은 켰을 때만 맨 뒤에 나옵니다.
11월 15일~12월에는 송년회, 1월에는 신년회가 기본으로 골라집니다.

## 맞춤 카드 (이름·회사·팀이 들어간 카드)

이 저장소는 공개 상태라서 맞춤 카드는 올리지 않습니다.

- `cards-my.csv`에 두면 `build.py`가 개인용 `app/index.my.html`을 따로 만듭니다. 두 파일 모두 `.gitignore`에 있습니다.
- 개인용 앱은 비공개 링크로만 올리고, `cards-my.csv` 원본도 그 링크에 함께 보관합니다.
- 공개용 `app/index.html`에는 '맞춤' 탭이 없습니다.
