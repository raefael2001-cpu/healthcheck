# 2행시 건배사 추천 앱: '짠(ZZAN)' 서비스 기획 및 개발 명세서

---

## 1. 프로젝트 개요 (Executive Summary)

* **서비스명(가칭):** 짠 (ZZAN)
* **슬로건:** "갑자기 돌아온 건배사, 3초 만에 짠!"
* **핵심 가치 제안 (Value Proposition):** 
  * 갑작스러운 건배사 지목 순간, 머뭇거림 없이 현장 분위기(상대방, 무드, 최신 트렌드)에 최적화된 2행시 건배사를 3초 만에 제공.
  * 단순 텍스트 나열을 넘어 **발성/호흡 특수기술(스타카토, 크레센도 등)**을 결합하여 실전 전달력과 재미 극대화.
* **주요 타깃:**
  * **Core:** 회식 건배사가 두려운 2030 사회초년생 및 직장인
  * **Sub:** 동창회, 청첩장 모임, 워크숍, 가족 모임 주최자 및 참가자

---

## 2. 핵심 기능 정의 및 UX 정책

### 2.1 상대 맞춤형 타깃 매트릭스 (Audience Engine)
상대방과의 관계 및 연령대에 따른 수위, 금기어, 발성 톤을 프리셋으로 분리 제어합니다.

| 타깃 모드 | 주요 상황 | 핵심 톤앤매너 | 추천 발성 기술 | 금기 사항 (Safety Filter) |
|---|---|---|---|---|
| **부장님/임원 (`BOSS_EXECUTIVE`)** | 경영진, 직속 상사, 공식 회식 | 예의 80% + 능청 20%, 회사 발전/건강/성공 | 크레센도, 콜앤리스폰스 | 지나친 신조어, 야근/퇴사/자학 드립 |
| **동기/또래 (`PEER_FRIEND`)** | 입사 동기, 친구, 사적 술자리 | 숏폼 호흡, 솔직한 공감, B급 드립, 밈 적극 반영 | 스타카토, 훅&드롭 | 진지한 훈계 톤, 낡은 아재 개그 |
| **청첩장/축하 (`WEDDING_PARTY`)** | 결혼 전 모임, 생일 파티 | 축복, 덕담, 감동 + 끝맛 반전 | 떼창형 합창 | 전 연인 관련 뉘앙스, 과도한 폭음 유도 |
| **가족/어르신 (`FAMILY`)** | 명절, 가족 모임, 회갑/칠순 | 무병장수, 화목, 따뜻한 리듬 | 정박자 2단 합창 | 빠른 템포, 불필요한 줄임말 |

### 2.2 트렌드 밈(Meme) 실시간 반영 파이프라인
* **트렌드 토글 (ON/OFF):** 사용자가 유행 밈 반영 여부를 원터치로 제어.
* **수명 주기 관리:** 
  * *Fresh (1~3주):* '동기/친구 모드'에 즉각 주입.
  * *Mainstream (1~3개월):* 전 연령 대상 사용 가능 검증 시 '부장님 모드' 확장.
  * *Expired (3개월 이상):* 자동 아카이빙 처리로 '갑분싸' 방지.

### 2.3 발성·호흡 '특수기술(Skill)' 시스템
건배사의 타격감과 리듬감을 부여하는 4대 호흡 가이드:
1. **스타카토 (Staccato):** 음절을 0.5초 간격으로 딱! 딱! 끊어 쳐서 좌중의 집중도를 폭발시키는 기술 (도트 인디케이터 `●` 제공).
2. **크레센도 (Crescendo):** 차분한 속삭임으로 시작해 마지막 단어에서 데시벨을 터뜨리는 빌드업 샤우팅.
3. **훅 & 드롭 (Hook & Drop):** 1행으로 방심하게 만든 뒤 2행에서 반전 단타로 종결.
4. **콜 & 리스폰스 (Call & Response):** 선창자가 단어를 던지면 좌중이 리듬을 타서 받아치는 떼창 구조.

### 2.4 인터페이스: 좌우 카드 스와이프 (Card Swipe Deck)
* **우측 스와이프 (Pick):** 마음에 드는 건배사 선택 ➔ 즐겨찾기 저장 및 즉시 전체화면 줌.
* **좌측 스와이프 (Pass):** 다음 추천 카드로 즉시 교체.
* **3초 긴급 랜덤 뽑기:** 앱 실행 후 스마트폰을 흔들면(가속도 센서) 즉시 검증된 프리셋 카드 팝업.

### 2.5 실전 망각 방지 (술자리 치팅 UX)
* **화면 꺼짐 방지 (Keep-Screen-On):** 건배사 카드를 고른 상태에서는 5분간 디스플레이 절전 방지.
* **원터치 대형 폰트 줌 (테이블 엿보기):** 카드를 탭하면 테이블 위에 폰을 둔 채 곁눈질(1m 거리)로도 다 읽을 수 있도록 48pt 이상의 고대비 폰트 모드 지원.
* *(고도화 과제 이관: 스마트워치 컴플리케이션 연동, OS 플로팅 헤드 오버레이, 귓속말 TTS 브리핑)*

## 3. 시스템 아키텍처 및 기술 스택

### 3.1 기술 스택 선정

| 영역 | 선정 기술 | 선정 이유 |
|---|---|---|
| **Frontend** | Flutter | 60fps 부드러운 스와이프 애니메이션, iOS/Android 단일 코드베이스 |
| **Backend** | FastAPI (Python) | 비동기 LLM 호출 최적화, 고성능 경량 RESTful API |
| **AI Engine** | Claude 3.5 Haiku / GPT-4o-mini | 저지연(1.5초 이내), 엄격한 JSON 구조화 출력 및 가성비 |
| **Database & Cache** | Redis + Supabase (PostgreSQL) | 상위 100개 빈출 단어 0.5초 컷 캐싱, 유저 피드백 데이터 저장 |
| **Local Storage** | Hive (Flutter) | 지하 주점 등 통신 불량 대비 비상 프리셋 50선 오프라인 캐싱 |

### 3.2 데이터 흐름 (Architecture Flow)
```
[사용자 입력 (단어, 타깃, 밈 여부)]
        │
        ▼
[Redis 캐시 확인] ──(Hit)──► [0.5초 컷 즉각 반환]
        │ (Miss)
        ▼
[백엔드 API 서버 (FastAPI)]
        │ ➔ 주간 트렌드 키워드 주입
        ▼
[LLM Engine] ──(Timeout / Error)──► [로컬/DB 검증 템플릿 폴백]
        │ (Success)
        ▼
[좌우 스와이프 카드 렌더링 (Flutter)]
```

## 4. API 명세서 (RESTful)

### 4.1 건배사 실시간 생성
* **URL:** `POST /api/v1/toasts/generate`
* **Request Body:**
```json
{
  "keyword": "연봉",
  "target_audience": "PEER_FRIEND",
  "enable_trend_meme": true,
  "preferred_skill": null
}
```
* **Response (200 OK):**
```json
{
  "status": "success",
  "data": {
    "toast_id": "toast_8921a",
    "keyword": "연봉",
    "target_audience": "PEER_FRIEND",
    "applied_trend": "폼 미쳤다",
    "skill_info": {
      "type": "STACCATO",
      "name_ko": "스타카토 펀치",
      "description": "0.5초 간격으로 음절마다 끊어서 타격"
    },
    "script": [
      {
        "line_number": 1,
        "syllable": "연",
        "sentence": "연차 쓰고 놀러 갈 생각만 하지 말고,",
        "role": "LEADER",
        "timing_guide": "차분하고 능청스럽게 운 띄우기"
      },
      {
        "line_number": 2,
        "syllable": "봉",
        "sentence": "봉!·인!·해!·제!·원!·샷!",
        "role": "ALL",
        "timing_guide": "반박자씩 딱딱 끊어서 함께 외치기"
      }
    ],
    "toast_trigger": "봉인해제!",
    "call_and_response": {
      "call": "선창: 연차 대신!",
      "response": "후창: 봉인해제!"
    }
  }
}
```

### 4.2 현장 반응 피드백 수집
* **URL:** `POST /api/v1/toasts/{toast_id}/feedback`
* **Request Body:**
```json
{
  "reaction": "SUCCESS",
  "target_actual": "PEER_FRIEND",
  "comment": "스타카토 리듬으로 끊어치니까 다들 빵 터졌습니다."
}
```

## 5. 백엔드 LLM 프롬프트 설계

```yaml
Role: "대한민국 회식 및 술자리 분위기를 단숨에 살리는 2행시 건배사 크리에이티브 디렉터"

Input:
  keyword: "{제시어 2글자}"
  target_audience: "BOSS_EXECUTIVE | PEER_FRIEND | WEDDING_PARTY | FAMILY"
  enable_trend_meme: true/false
  current_trends: ["럭키비키", "폼 미쳤다", "뉴진스", "중꺾마"]

Rules:
  1. 각 행은 반드시 제시어의 1, 2번째 음절로 시작할 것.
  2. 선창(1행)과 후창(2행) 구조를 명확히 분리할 것.
  3. 마지막 단어는 닫힌 음절(받침)이나 파열음(ㅋ, ㅌ, ㅊ, ㅍ, ㄲ, ㅆ)을 활용해 타격감을 살릴 것.
  4. 타깃별 안전 필터를 엄수할 것 (BOSS 모드에서는 자학/퇴사 드립 엄금).
  5. 반드시 STACCATO, CRESCENDO, HOOK_DROP, CALL_RESPONSE 중 1개의 특수기술을 매핑할 것.
  6. 출력은 마크다운 코드블록 없는 순수 JSON 포맷으로만 응답할 것.
```

```

  - FastAPI 서버 구현 및 LLM 비동기 연동
  - Redis 캐싱 레이어 세팅 (상위 키워드 지연시간 0.5초 달성)

  - 오프라인 모드(통신 단절 시 비상 프리셋 작동) 검증

```
