# 오늘의 바디체크 (1단계)

수면 · 아침 컨디션 · 식사 규칙성 · 운동을 하루 1분으로 기록하는 개인용 웰니스 앱(PWA).
AI 없이 동작하고, 회원가입·이름·연락처 없이 쓴다. 기록은 폰 안에만 저장한다.

## 1단계 기능

- **시작:** 키·몸무게·성별·만 나이만 입력. 목표 수면·주간 운동 목표는 나중에 설정에서.
- **오늘:** 수면(잠든·깬 시각), 아침 컨디션(5단계), 식사 규칙성(아침·점심·저녁 제시간/늦게/거름, 야식), 운동(했음/안 함, 시간·종류).
- **피드백:** 기록 값에 따른 규칙과 미리 쓴 문구 (`js/feedback.js`의 `PHRASES`).
- **주간 리포트:** 기록 일수, 평균 수면, 운동 횟수·총시간, 컨디션 추세. 미기록은 0으로 계산하지 않고, 표본이 적으면 안내.
- **알림:** 사용자가 정한 시각에 기록 알림 (앱 실행 중 타이머 + 설치 시 주기적 백그라운드 확인 + 캘린더 .ics 등록).
- **데이터:** 기본 정보 수정, 기록 개별 삭제, 전체 삭제, 백업 파일 저장·불러오기.

## 1.5 추가 (사용 피드백 반영, 2026-10-30)

- **몸 상태 해시태그:** `#두통` `#무릎통증` 등 증상 태그 + 원인 태그 + 한 일(대처) + 효과(있음/없음/모름) + 메모 100자. 하루 여러 건. 태그는 직접 추가 가능.
- **저녁 유산균:** 먹었어요/안 먹었어요 하루 1번. 저녁 알림에 포함, 주간 리포트에 '기록한 N일 중 M일'.
- **컨디션 원인:** 아침 컨디션에 원인 해시태그(`#수면부족` `#과식` `#찬음식`…)와 메모.
- **피드백:** 같은 증상에 예전에 효과 있던 대처를 알려 줌. 컨디션이 낮은데 원인이 비어 있으면 안내.
- **주간 리포트:** 맨 위 한 줄 결론, 지난주 대비 ↑↓, 가장 좋았던 날, 효과 있던 대처 TOP 3(최근 8주), 이번 주 몸 상태·컨디션 낮은 날의 원인 집계.

## 2단계로 미룬 것

- 삼성헬스 에너지(기상) 점수 입력 — 수동 입력 칸, 이후 삼성헬스 SDK 연동
- 꾸준함 장치(듀오링고식) — 연속 기록일, 주 1회 보호권, 최소 완료 기준, 완료 축하
- 헬스커넥트(운동·수면, 플랜핏 경유), 인바디·음식 사진 인식

## 설치 (안드로이드)

1. 크롬 또는 삼성 인터넷에서 GitHub Pages 주소를 연다.
2. 메뉴 → **홈 화면에 추가** 또는 **앱 설치**.
3. 알림을 쓰려면 설정 → 기록 알림에서 시각을 켜고 저장. 정확한 정시 알림은 "캘린더에 매일 알림 등록".

## 구조

```
index.html, styles.css      화면 틀과 스타일
js/model.js                 데이터 모델·출처·검증·날짜 계산
js/db.js                    IndexedDB 저장소, 외부 기록 넣기(ingestExternal), 백업·삭제
js/feedback.js              규칙 기반 피드백과 문구
js/report.js                주간 통계와 안내 문장
js/reminders.js             알림 권한·예약·캘린더 파일
js/app.js                   화면(시작/오늘/주간/설정)
js/integrations/            2단계 연동 자리 (헬스커넥트·플랜핏·삼성헬스·인바디 사진·음식 사진)
sw.js                       오프라인 캐시, 백그라운드 알림
docs/data-model.md          데이터 구조
docs/integrations.md        2단계 연동 조건 확인 결과
tests/logic.test.mjs        계산 로직 테스트 (node --test tests/logic.test.mjs)
```

개인 습관 기록용이며 의료적 판단을 대신하지 않는다.
